# SVVIP
# 抵抗之弧 · 战略指挥中心

一个纯前端的回合制战略推演指挥台。单文件 HTML，双击即玩，无需构建、无需依赖。

🎮 在线试玩：https://qaq271911.github.io/SVVIP/

## 玩法
在节点地图上推进回合，管理资源与局势指标，处理滚动新闻事件，把战线一步步推向目标。左右侧栏可收起，点击地图节点查看详情并下达行动。

## 当前优化方向
- 保留自由模式，不增加固定难度选项。
- 在游戏内部根据胜负分、失败分、资源压力、控制节点、战争态势和游戏年份动态判定难度：轻松、标准、困难、地狱。
- 难度标签仅作为实时反馈，不改变已保存存档中的核心规则。
- 优先优化目标可读性、战局复盘和局势提示。
- 所有改动继续保持纯前端、单文件和双击即玩的特性。

## 动态难度建议
系统可以综合以下指标计算压力等级：

- 胜利分与失败分的差距
- 可用积分与日产出
- 已控制节点占比
- 撤防、制裁、恐惧和联盟压力
- 玩家连续成功或连续受挫的次数
- 游戏年份和对手的推进速度

然后在界面中展示例如「当前评估：困难」及原因摘要，例如「敌方攻势升高」「资源压力较大」或「局势正在好转」。

## 运行
浏览器直接打开 `index.html` 即可，clone 下来本地打开也一样。

## 技术
原生 HTML / CSS / JavaScript，无框架、无外部资源。OKLCH 战术配色 + SVG 节点地图 + 机械翻页时钟 + 双侧浮动面板，全部塞在一个文件里。
