# SVVIP
# 抵抗之弧 · 战略指挥中心

一个纯前端的回合制战略推演指挥台。单文件 HTML，双击即玩，无需构建、无需依赖。

🎮 在线试玩：https://qaq271911.github.io/SVVIP/

## 玩法
在节点地图上推进回合，管理资源与局势指标，处理滚动新闻事件，把战线一步步推向目标。左右侧栏可收起，点击地图节点查看详情并下达行动。

## 优化分支功能
- 保留自由模式，不增加固定难度选项。
- 游戏内部根据胜负分、失败分、资源压力、控制节点、战争态势和年份动态判定威胁等级。
- 增加独立实验页面 `v2.html`，包含动态难度、随机事件、撤销、保存、导出、地图视图和移动端适配。
- 增加全球一级行政区浏览页面 `global-provinces.html`。
- 行政区数据按国家按需加载，支持国家搜索、选择、拖动、缩放和区域悬停提示。
- 地图边界优先使用 `geoBoundaries` 的 `gbOpen` / ADM1 数据，遵守 CC BY 4.0 署名要求。
- 原始 `index.html` 保留为主版本，不会由实验页面覆盖。

## 动态威胁评估
系统综合胜负差、资源储备、节点控制、稳定度、补给、连续局势变化和年份压力来判定：轻松、标准、困难、地狱。

评估内容只作为实时反馈，不增加固定难度档位，也不改变现有存档规则。

## 运行
浏览器直接打开任意 HTML 文件即可：

- `index.html`：原始完整版本
- `v2.html`：优化实验版本
- `global-provinces.html`：全球一级行政区浏览和边界加载

## 全局行政区划说明
`global-provinces.html` 使用 ADM1 概念表示国家一级行政区划。因此：

- 中国、伊朗等国家以省级或省级等效单位展示
- 美国以州展示
- 英国以一级行政区展示
- 其他国家使用各自的一级行政区名称

数据不是手工复制到仓库中，而是在浏览器中按国家请求加载，以减少单文件体积并保持数据更新。

## 技术
原生 HTML / CSS / JavaScript，无框架、无外部资源。部分页面使用浏览器本地存储和公共行政区划数据接口。

## 数据来源
行政区界线由 [geoBoundaries](https://www.geoboundaries.org/) 提供，采用 `gbOpen` 发布集并遵循 CC BY 4.0。使用时应保留页面中的署名链接。
